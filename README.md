# Serverless Task Management API

A Python-based Task Management REST API built to practice serverless-style backend development, CRUD operations, and database integration.

## Live Demo

**API Base URL:** https://abubakar.pythonanywhere.com

**Test endpoint:** https://abubakar.pythonanywhere.com/tasks

The API supports creating, retrieving, updating, and deleting tasks.

## Tech Stack

- Python
- Flask
- SQLite
- REST API
- PythonAnywhere hosting

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/tasks` | Retrieve all tasks |
| POST | `/tasks` | Create a task |
| GET | `/tasks/{id}` | Retrieve a task |
| PATCH | `/tasks/{id}` | Update a task |
| DELETE | `/tasks/{id}` | Delete a task |
